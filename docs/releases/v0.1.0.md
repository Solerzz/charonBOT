# Charon v0.1.0 — Infraestrutura

Primeira fundação executável do Charon.

## Destaques

- TypeScript strict e Node.js 20+.
- Configuração validada antes de qualquer conexão externa.
- Prisma 7 preparado para Supabase PostgreSQL.
- Logs JSON com proteção de credenciais.
- Cliente Discord com roteamento explícito e `/status`.
- Testes e CI para typecheck, comportamento e build.

## Fora desta versão

Voice Creators, calls temporárias e seus controles começam na `v0.2.0`.
